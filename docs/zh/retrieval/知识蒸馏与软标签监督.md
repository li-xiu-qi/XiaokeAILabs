# 知识蒸馏与软标签监督

> 阅读导航：[检索与排序全景](README.md) · [Embedding 蒸馏](embedding/Embedding蒸馏.md) · [重排序蒸馏](reranking/重排序蒸馏.md) · [文本 ColBERT 蒸馏](colbert/文本多向量检索模型蒸馏.md) · [视觉多向量检索模型蒸馏](colbert/视觉多向量检索模型蒸馏.md)

在信息检索系统的模型训练中，人工标注的数据通常是二元的硬标签：文档 A 是相关正例（标签为 1），文档 B 和 C 是负例（标签为 0）。但在实际的检索场景里，相关性往往不是非黑即白的：文档 B 可能完全无关，而文档 C 可能是部分相关的参考。只靠人工硬标签，模型只能把 B 和 C 同等推远，丢失了候选之间的相对强弱信息。

知识蒸馏通过引入能力更强、参数量更大的教师模型（如高精度交叉编码器或大尺寸多模态模型），由教师对多个候选输出连续的置信度分数，并将这些分数转化为学生模型的监督目标。

本文系统梳理检索与表征学习中知识蒸馏的核心机理，推导连续软标签的数学形态、温度参数的梯度调节机制、跨架构信号传递范式以及教师优势的适用边界。

---

## 一、问题背景与监督形态

传统监督学习依赖人工真值构建的二元标签。这种离散监督在工程落地中面临两大约束：
1. 标注成本高昂，难以覆盖大规模长尾查询与多领域候选；
2. 忽略了负样本之间的语义层级差异。一个部分相关的负例与一个完全无关的负例，在交叉熵损失中承受相同的推离惩罚。

教师网络在海量语料上预训练后，其输出的连续打分蕴含了候选集合之间的相对相似度关系，这种信息通常被称为暗知识。将教师打分转化为平滑的概率分布或相对差值，能够为轻量学生网络提供更细致的优化方向。

根据教师模型向学生传递信息粒度的不同，训练信号主要分为三类数学形态：
- 离散硬排序：仅提取教师打分的相对顺序，用于生成伪标签；
- 连续软概率分布：保留候选集合全量置信度梯级，通过 KL 散度进行全局对齐；
- 成对分数差值：拟合正负例之间的相对间距，抵御跨架构绝对分数尺度的失真。

## 二、目标分布与温度调节

在构建软概率分布时，教师输出的未归一化打分需要通过 Softmax 函数映射为概率质量。

设候选池由查询 $q$ 和 $K$ 个候选文档 $\{d_1, d_2, \dots, d_K\}$ 组成。引入温度超参数 $\tau > 0$，教师与学生模型的归一化预测概率分别为：

$$P_T(d_k \mid q) = \frac{\exp(s_T(q, d_k) / \tau)}{\sum_{j=1}^K \exp(s_T(q, d_j) / \tau)}$$

$$P_S(d_k \mid q) = \frac{\exp(s_S(q, d_k) / \tau)}{\sum_{j=1}^K \exp(s_S(q, d_j) / \tau)}$$

温度参数 $\tau$ 在蒸馏过程中承担分布平滑器的作用：
- 当 $\tau \to 0$ 时，分布退化为 One-Hot 极化分布，仅保留最高分候选，丢失暗知识；
- 当 $\tau$ 适当增大时，各候选之间的概率差异被拉平，次优候选与负例之间的细微区分度被放大；
- 对应的 KL 散度损失函数定义为：
  $$\mathcal{L}_{\text{KL}} = \tau^2 \cdot D_{\text{KL}}(P_T \parallel P_S) = \tau^2 \sum_{k=1}^K P_T(d_k \mid q) \log \left( \frac{P_T(d_k \mid q)}{P_S(d_k \mid q)} \right)$$

损失函数前乘以 $\tau^2$ 因子，是为了补偿温度缩放对 Softmax 求导带来的 $1/\tau^2$ 梯度衰减，使反向传播给学生参数的梯度幅度保持稳定。

## 三、损失函数与优化目标

在不同的检索任务与计算开销限制下，蒸馏优化目标主要采取以下两种形式：

### 1. 全局分布 KL 散度损失

适用于具有明确固定候选集合的场景。学生通过最小化两组离散概率分布之间的相对熵，使候选页面的全局排序序列逼近教师模型。

### 2. 成对边际差值损失（Margin-MSE）

在检索排序中，两个候选之间的相对优劣差值往往比绝对分布更为关键。Margin-MSE 直接约束学生模型拟合正负例之间的得分差：

设正例文档为 $d^+$，负例文档为 $d^-$。教师给出的差值为 $\Delta_T = s_T(q, d^+) - s_T(q, d^-)$，学生预测的差值为 $\Delta_S = s_S(q, d^+) - s_S(q, d^-)$。优化目标为均方误差：

$$\mathcal{L}_{\text{Margin-MSE}} = \left( \Delta_S - \Delta_T \right)^2 = \left( [s_S(q, d^+) - s_S(q, d^-)] - [s_T(q, d^+) - s_T(q, d^-)] \right)^2$$

Margin-MSE 的优势在于避开了不同模型绝对打分范围不一致的问题。即使教师模型输出的分数范围在较大的无约束区间，而学生模型因余弦相似度被约束在有限区间内，通过拟合差值依然能保持稳定的梯度更新。

## 四、跨架构信号传递机制

不同模型架构的物理输出维度不同，蒸馏的信号传递范式呈现出明显的分类学分化：

| 蒸馏范式 | 典型适用模型 | 教师与学生输出接口 | 核心对齐机制 |
|---|---|---|---|
| **词表级分布对齐** | 自回归大语言模型 | 词表维度全量 Logits | 逐 Token 对全词表 Softmax 进行 KL 散度对齐 |
| **成对标量差值拟合** | 单向量双塔、重排序模型 | 标量相似度分数 | 基于三元组计算 Margin-MSE，拟合排序梯级差 |
| **聚合打分分布拟合** | 多向量晚期交互、多模态模型 | MaxSim 算子或跨模态局部交互分 | 对批内候选总分进行长度归一化，再构建局部 Softmax 分布 |

- **自回归生成蒸馏**：教师与学生逐步预测下一个 Token，优化的核心在于词表级别的语义保真度；
- **双塔单向量蒸馏**：教师为全注意力交互的交叉编码器，学生为解耦双塔，通过 Margin-MSE 弥补双塔过早池化丢失的交互信息；
- **多向量与多模态蒸馏**：学生端内部包含数十到数百个 Token 向量或图像 Patch，内部无法一一配对，必须依赖聚合算子（如 MaxSim）计算出标量分数后，在批次候选维度完成软标签对齐。

## 五、误差边界与适用条件

在工程实践中，知识蒸馏并不天然保证带来正面收益，其实际效果受制于以下边界条件：

1. **教师优势门禁**：
   蒸馏有效的前提是教师模型在目标垂直任务上的评测表现严格优于学生基线。若教师本身在特定排版、密集表格或生僻领域缺少先验判别力，其输出的软标签将沦为带噪干扰信号，导致学生模型准确率落后于纯监督训练；
2. **严密因果对照设计**：
   评估蒸馏收益时，必须设立同等训练步数、同等超参数搜索预算的纯监督微调对照组。若不设监督对照，容易将参数微调本身的收益误归因于教师信号的有效性；
3. **软硬标签联合加权**：
   在绝大多数场景中，结合人工标注硬标签与教师软标签的多任务学习更为稳健：
   $$\mathcal{L}_{\text{total}} = \alpha \mathcal{L}_{\text{supervised}} + (1 - \alpha) \mathcal{L}_{\text{distill}}$$
   由人工真实样本提供底层锚定，避免模型过度拟合教师的系统性偏见。
