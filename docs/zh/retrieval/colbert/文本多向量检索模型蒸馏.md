# 文本多向量检索模型蒸馏

> 阅读导航：[检索与排序](../README.md) · [ColBERT 系列导览](README.md) · [晚期交互与多向量检索](晚期交互与多向量检索.md) · [文本多向量检索模型微调](文本多向量检索模型微调.md) · [多向量索引与剪枝加速](多向量索引与剪枝加速.md) · [知识蒸馏与软标签监督](../知识蒸馏与软标签监督.md) · 实验代码：[`colbert-distillation`](../../../../experiments/colbert-distillation/README.md)

在科学文献重排任务中，关键词检索初筛召回的候选往往都包含相同的专业术语，但仅有少数论文真正提供了支持或反驳核心论断的直接证据。如果仅依赖人工标注的单一正例进行监督微调，剩余未标注候选之间的相关性梯度便无法体现在离散标签中。

引入参数量更大、判别能力更强的单向量教师模型对候选进行连续打分，能够将候选文献之间的相对排序偏好迁移给轻量多向量学生。关于知识蒸馏的软目标平滑、温度缩放与跨架构信号传递机制，参见 [知识蒸馏与软标签监督](../知识蒸馏与软标签监督.md)。

本文基于本仓库在 `experiments/colbert-distillation/` 中的实测记录，介绍跨架构候选分数蒸馏的实现机制、训练参数配置，以及在 SciFact 测试集上对比未微调基线、纯标签监督组与教师模型本身的客观实测数据。

---

## 一、核心原理

### 1. 跨架构软标签概率分布

本实验属于跨架构候选分数蒸馏：教师为单向量模型 Qwen3-Embedding-8B，学生为多向量模型 ColBERTv2。两者内部表征形态不同，但在输入相同的查询与四篇候选文献时，均能输出一组标量匹配分数。

对于单条查询 $q$ 及四篇候选文献 $\{d_1, d_2, d_3, d_4\}$：
- 教师模型计算查询与文档的单向量余弦相似度 $s_T(q, d_i)$，在温度 $\tau_T = 0.05$ 下归一化为教师概率分布：
  $$p_T(i \mid q) = \frac{\exp(s_T(q, d_i) / 0.05)}{\sum_{j=1}^4 \exp(s_T(q, d_j) / 0.05)}$$
- 学生模型计算查询与文档的 MaxSim 分数 $s_S(q, d_i)$，归一化为预测概率分布：
  $$p_S(i \mid q) = \frac{\exp(s_S(q, d_i))}{\sum_{j=1}^4 \exp(s_S(q, d_j))}$$

### 2. KL 散度蒸馏目标函数

训练目标是最小化学生分布与教师分布之间的 KL 散度：

$$\mathcal{L}_{\mathrm{KD}} = D_{\mathrm{KL}}(p_T \parallel p_S) = \sum_{i=1}^4 p_T(i \mid q) \log \frac{p_T(i \mid q)}{p_S(i \mid q)}$$

学生模型在反向传播时，通过拟合教师在四个候选之间建立的平滑概率阶梯，学习更细致的排序偏好。

## 二、实验设计

### 1. 教师与学生模型配置

- 教师模型：Qwen3-Embedding-8B（80 亿参数单向量模型）
- 学生模型：ColBERTv2.0（约 1.10 亿参数多向量模型）
- 训练步数：128 步
- 批次大小：每批 4 条查询（每步处理 16 个查询-文档对）
- 优化器：AdamW，学习率 3e-6
- 序列长度：查询固定扩展至 32 个 Token，文档截断至 180 个 Token
- 训练随机种子：20261107

### 2. 候选池与正负例构造

基于 BEIR SciFact 数据集构建训练样本：
- 训练查询：从合格训练池中选出 128 条具有句级证据的科学论断查询；
- 候选构成：每条查询配备 1 篇标注相关文献与 3 篇 BM25 召回的未标注候选；
- 监督对照组：使用相同初始学生权重与数据批次，将正例文档的目标设为近似 One-Hot 标签（`[50, 0, 0, 0]`），仅进行纯硬标签监督微调；
- 测试集：300 条独立测试查询，每条查询固定 BM25 前 30 个候选文档。

## 三、过程与开销

### 1. 训练吞吐与耗时测量

在具备统一内存的单机硬件环境中，学生模型执行 128 步蒸馏前向与反向传播的纯计算耗时约为 26 秒（不包含离线教师打分与最终评测耗时）。

### 2. 硬件资源与运行环境

实验在单机硬件环境下完成，PyTorch 2.14.0 配合 PyLate 框架，环境配置与依赖校验值保存在 `experiments/colbert-distillation/configs/source-hashes.json`。

## 四、实验结果与观察

### 1. 四组重排性能对比指标

在 300 条测试查询与相同候选池上，四组模型的重排指标测量结果如下：

| 评估方案 | 模型角色 | nDCG@10 | MRR@10 |
|---|---|---:|---:|
| ColBERTv2 (未微调基线) | 学生初始状态 | 0.6536 | 0.6262 |
| 标签监督训练组 | 纯硬标签对照 | **0.6686** | **0.6452** |
| 教师分数蒸馏组 | 软概率分布学习 | 0.6653 | 0.6421 |
| Qwen3-Embedding-8B | 教师自身表现 | 0.7341 | 0.7044 |

### 2. 数据层面的直接观察

结合统计学重采样与测量记录，本次实验直接观察到的客观事实包括：
1. 教师模型自身的重排表现明显高于学生初始模型（nDCG@10 达到 0.7341，领先初始学生约 0.08）；
2. 相比未微调基线，教师分数蒸馏后学生的 nDCG@10 提升了 +0.0117，经配对 Bootstrap 重采样的 95% 置信区间为 [0.0012, 0.0222]；
3. 相比使用相同样本与预算的纯标签监督组，蒸馏组的 nDCG@10 略低 0.0033，差异的 95% 置信区间为 [−0.0113, 0.0041]（跨过了零点）；
4. 在当前 128 步的小步数与 4 候选局部对比设置下，教师给出的软分布改善了学生的排序质量，但相较于纯监督微调并未体现出显著的统计学优势。
