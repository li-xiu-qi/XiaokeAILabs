# ColBERT 与多向量检索系列

> 阅读导航：[English](../../../en/colbert/README.md) · [检索与排序](../README.md) · [全局实验地图](../../README.md)

在复杂长文档、专业学术研报与排版图表检索中，单向量全局池化容易造成局部实体信息的稀释与丢失。ColBERT 晚期交互架构通过保留词元级别的向量序列，在查询阶段通过 MaxSim 细粒度对齐算子计算匹配分数，兼顾了离线独立建库与接近交叉编码器的交互精度。

本系列涵盖多向量晚期交互的数学机理、存储残差量化压缩与剪枝加速、文本领域微调与蒸馏，以及跳过 OCR 的页面级视觉多向量端到端检索。

## 四、阅读与复现建议

1. **先看机制再看实验**：建议先通读 [晚期交互与多向量检索](晚期交互与多向量检索.md) 理解 MaxSim 计算本质，再进入具体的微调与蒸馏实验；
2. **通识理论一次性掌握**：关于软目标平滑、温度参数调节与三种跨架构蒸馏范式的通用数学推导，参见 [知识蒸馏与软标签监督](../知识蒸馏与软标签监督.md)；
3. **实验严谨边界**：本系列公布的微调与蒸馏指标均为固定候选重排场景，反映的是在既有候选池内的排序调整能力，不能等同于全库检索召回率。具体运行环境、复现脚本与原始证据 JSON 请访问各实验目录。
