# 视觉多向量检索模型蒸馏

> 阅读导航：[多向量检索系列](README.md) · [视觉多向量检索](视觉多向量检索.md) · [视觉多向量检索模型微调](视觉多向量检索模型微调.md) · [知识蒸馏与软标签监督](../知识蒸馏与软标签监督.md)

在页面级视觉文档检索中，监督微调通过正负图文对的二元对比损失调整模型权重。这种离散监督将样本明确区分为相关与不相关两类，但在真实场景中，不同负例与查询的相关程度往往存在层级差异：完全无关的页面与部分相关的页面在硬标签下被同等推远，模型无法感知候选之间的语义梯度。

交叉编码器具有全注意力交互机制，能够对图文匹配给出细粒度的连续置信打分，但计算复杂度高，无法用于全库候选召回。知识蒸馏的目标是借助强多模态交叉模型的打分分布，将其转化为连续的软标签，指导轻量视觉多向量模型在学习离散分类边界的同时，拟合候选页面之间的相对排序关系。关于知识蒸馏与软标签平滑的通用数学推导与三大范式分类，参见 [知识蒸馏与软标签监督](../知识蒸馏与软标签监督.md)。

本文基于合成财务报表场景，详细记录多向量晚期交互架构下的软标签构建、局部对齐损失函数设计、8 步训练开销，以及内部测试集与扩大规模独立复测集的客观实测数据。

---

## 一、核心原理

### 1. 教师与学生概率分布

在批次训练过程中，每个批次包含若干个查询及其对应的候选页面集合。

教师模型采用视觉语言重排序器，接收查询文本与页面图像输入，经 Sigmoid 激活后输出浮点置信度分数 $t_{ij}$。通过引入温度参数 $\tau_T$，将候选页面的得分转化为教师目标概率分布：

$$p^T_{ij} = \frac{\exp(t_{ij} / \tau_T)}{\sum_k \exp(t_{ik} / \tau_T)}$$

学生模型通过视觉编码器将页面映射为 Patch 向量序列，并使用投影层将查询文本映射为 Token 向量序列。在计算长度归一化的晚期交互 MaxSim 分数 $\bar{s}_{ij}$ 后，同样引入学生温度参数 $\tau_S$ 构建预测概率分布：

$$p^S_{ij} = \frac{\exp(\bar{s}_{ij} / \tau_S)}{\sum_k \exp(\bar{s}_{ik} / \tau_S)}$$

### 2. 联合训练目标

模型优化的总体损失函数由两部分按等权加权构成：

$$\mathcal{L} = 0.5 \cdot \mathcal{L}_{\mathrm{supervised}} + 0.5 \cdot D_{\mathrm{KL}}(p^T \parallel p^S)$$

其中第一项为基于真实正负配对的标准对比损失，促使正例得分超越所有负例；第二项为两组连续概率分布之间的 KL 散度，约束学生模型的候选排序梯队与教师打分趋于一致。

## 二、实验设计

### 1. 模型架构与超参数

实验基于 ColPali 视觉多向量架构进行，图像骨干与语言模型基础参数保持冻结，仅对线性投影层挂载 LoRA 适配器进行梯度更新。

核心运行参数配置如下：
- 教师模型：Qwen3-VL 架构开源重排序器
- 学生模型：ColSmol 架构搭配 LoRA 适配器
- 学习率：1e-5
- 训练步数：8 步
- 查询批大小：2
- 优化器：AdamW
- 蒸馏温度：教师温度 0.1，学生温度 0.02
- 损失配比：监督对比损失权重 0.5，KL 散度损失权重 0.5

### 2. 数据集划分

数据集采用隔离规则构建的合成报表：
- 训练集：包含 96 张合成报表页面与 288 个配对查询
- 内部测试集：包含 32 张独立报表页面与 96 个查询
- 独立复测集：包含 64 张独立报表页面与 192 个查询

## 三、过程与开销

### 1. 训练损失轨迹

实验在具备大容量统一内存的单机环境中执行，8 个优化步长的损失下降轨迹如下：
- Step 1: 0.0531
- Step 2: 0.1186
- Step 3: 0.0293
- Step 4: 0.0222
- Step 5: 0.0511
- Step 6: 0.0279
- Step 7: 0.0361
- Step 8: 0.0445

### 2. 峰值显存测量

在加载学生模型、LoRA 梯度以及前向计算图的状态下，实测峰值分配显存为 8,245,522,944 字节，折合约 7.68 GiB。模型在消费级或工作站显卡上均能稳定完成小批量梯度更新。

## 四、实验结果与观察

评估分别在训练同源的内部测试集，以及扩大候选池规模的独立测试集上进行，以首位命中率（Recall@1）与前五位命中率（Recall@5）作为客观度量。

### 1. 内部测试集指标

内部测试集包含 32 个候选页面与 96 条评测查询，三组模型的测量数据如下：

| 实验组别 | 监督信号 | Recall@1 | Recall@5 |
|---|---|---:|---:|
| 未微调基线 | 无额外训练 | 87 / 96 (90.63%) | 96 / 96 (100.0%) |
| 监督微调 | 纯正负对比损失 | 88 / 96 (91.67%) | 96 / 96 (100.0%) |
| 蒸馏微调 | 对比损失与教师 KL 散度 | 88 / 96 (91.67%) | 96 / 96 (100.0%) |

在 32 个候选页面的检索环境下，监督微调与蒸馏微调在 96 个测试查询上的首位命中数完全一致，相对未微调基准均提升了 1 条正确命中。

### 2. 独立评测集指标

为了检验模型在更大检索池下的排序稳定性，评测引入独立收集的 64 张报表页面与 192 条查询进行复测：

| 实验组别 | 候选池规模 | Recall@1 | Recall@5 |
|---|---:|---:|---:|
| 未微调基线 | 64 页候选 | 149 / 192 (77.60%) | 186 / 192 (96.88%) |
| 监督微调 | 64 页候选 | 154 / 192 (80.21%) | 187 / 192 (97.40%) |
| 蒸馏微调 | 64 页候选 | 151 / 192 (78.65%) | 186 / 192 (96.88%) |

在候选池扩大到 64 页后，三组模型的首位命中率均出现不同程度的下降，但排序指标表现出细微分化。

### 3. 数据层面的直接观察

结合上述两组测试数据，本次实验直接观察到的客观事实包括：
1. 内部测试集中，引入蒸馏损失与单纯使用监督对比损失的准确率表现持平；
2. 独立测试集中，监督微调相比原始未微调模型提升了 5 个首位命中样本，蒸馏微调相比原始模型提升了 2 个首位命中样本；
3. 在当前每批仅处理 2 个查询与对应候选的轻量批次设置下，教师给出的软分布对最终学生模型排名的增量未体现出高于硬标签监督的指标优势。
