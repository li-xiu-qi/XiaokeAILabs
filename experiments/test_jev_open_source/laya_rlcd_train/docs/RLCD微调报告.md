# laya RLCD 训练在 NVIDIA GB10 单卡上的复现报告

| 项目 | 实验配置与环境参数 |
| :--- | :--- |
| 计算平台 | NVIDIA DGX Spark（NVIDIA GB10 Grace Blackwell，aarch64，121 GiB 统一内存，sm_121，驱动 580.173.02） |
| 基础软件栈 | Ubuntu 24.04 LTS，Python 3.12，PyTorch 2.14.0+cu130，Transformers 5.19.0，Datasets 5.1.0 |
| 实验代码版本 | laya 0.4.1（仓库 main 分支 tarball），下载源经 hf-mirror 镜像，禁用 xet 加速通道 |
| 底座模型 | convaiinnovations/laya English checkpoint（ModernBERT-large 421M） |
| 数据集构成 | LocalLLaMA/typed-decisions：训练集 1200 案例（拆分为 5600 训练 items 与 400 校准 items），测试集 400 案例（共计 2000 道 held-out 决策题） |
| 随机性控制 | seed 0，单次端到端运行 |
| 训练算力消耗 | 4 epochs，352 optimizer updates，端到端耗时约 27 分钟（含训练及前后两次全量 2000 题评估） |

### 评测目标与范围边界

本报告是本次复现实验的唯一正式记录。评测目标聚焦于验证 RLCD（Reinforcement Learning for Calibrated Decisions）算法在单张 NVIDIA GB10 架构上的数值可复现性，考察从 base checkpoint 到微调后模型的决策准确率、校准误差（ECE）、Brier 分数以及各题型细分表现，并与 laya 官方公布的 Kaggle 2xT4 实验数据及 TypeSafe Jev 官方基线对齐。

本实验未覆盖 soft accuracy 与 per-workflow 细分维度的统计，且未对多随机种子进行重复采样。此外，关于校准误差，报告内记录的 ECE 仅反映基于本次 400 个校准样本拟合温度后的计算结果，由于分桶与校准实现细节未完全统一，该指标与官方后校准（post-temperature）数字不构成严格同口径对比。

## 单卡复现确认 RLCD 有效，综合准确率达到 0.751

在 NVIDIA GB10 单卡环境下，RLCD 训练配方在保持有效 batch 64 的条件下完整复现了官方声明的能力跳升。模型在 400 案例共 2000 道 held-out 测试题上的综合准确率由微调前的 0.3625 提升至 0.7510，绝对增幅达到 38.85 个百分点，同时 Brier 分数从 0.3155 优化至 0.0576。

该表现跨过了两道关键基线，比 TypeSafe Jev 1.13.0 官方 zero-shot 基线（0.727）高出 2.4 个百分点，且突破了数据集标注者的自一致性上限（0.735）。相较于 laya 官方在 2xT4 硬件上报告的 0.766 准确率，本次复现结果落后 1.5 个百分点，但在概率预测质量（Brier 分数 0.0576 对比官方 0.062）上略有优势。整个训练与前后评估流程在 27 分钟内完成，统一内存未出现承压现象。

## 实验方法与等效配置推导

本次实验的核心工程改动在于将多卡分布式训练转为单卡梯度累积执行。官方开源的参考训练脚本针对 Kaggle 提供的免费双卡 T4 环境设计，基于 DistributedDataParallel（DDP）组织计算。在 DGX Spark 拥有 121 GiB 统一内存的硬件条件下，单卡具备充裕的显存预算，因此实现中移除了 DDP 封装，改用单卡累积逻辑。

为严格对齐官方训练动态，训练参数根据 laya 源码 train.py 内 TrainConfig 的等效注释设定：单步 micro_batch 设置为 8，gradient_accumulation_steps 设置为 8，使单一优化器更新步对应的有效批大小精确维持在 64。底座模型采用 ModernBERT-large（421M 参数），启用 AMP bf16 混合精度与梯度检查点（gradient checkpointing）。

RLCD 损失函数设置中，每个决策项生成 4 个高斯扰动采样（rl_samples=4），扰动标准差 sigma 随训练步数从 0.4 线性退火至 0.1。奖励信号综合考虑球形评分规则（Spherical Scoring Rule，权重 w_sph=0.75）与等级概率评分规则（Ranked Probability Score，权重 w_rps=1.0），并在优势归一化后执行 REINFORCE 策略梯度更新。优化器针对骨干网络与决策头分别设置学习率，encoder_lr 为 2.5e-5，head_lr 为 1e-4，输入序列最大长度限制为 512，决策头序列最大长度限制为 192。

## 训练动态与收敛过程

模型在 4 个训练轮次中完成了 352 次优化器权重更新，损失数值表现出单调下降并在末期趋于稳定的特征。各 epoch 的平均 loss 依次为：epoch 1 记录 0.8349，epoch 2 记录 0.7846，epoch 3 记录 0.7350，epoch 4 记录 0.7441。最后一个轮次中 loss 出现轻微震荡，策略梯度与辅助监督项达到相对平衡。

任务于 18:49 正式启动，19:16 完成最终检查点落盘与评估数据导出，累计耗时约 27 分钟。该时间开销不仅涵盖了 352 步前向、扰动采样与反向传播，还包含了训练开始前与结束后对 2000 道测试题分别执行的两次完整推理。GB10 的统一内存在整个训练生命周期内占用平稳，内存看门狗全程未触发任何告警或驱逐动作。

## 评估指标与细分题型表现

评估针对 400 个未参与训练的案例（held-out test split）展开，共计对应 2000 道决策题目。微调前后的核心指标变动如下表所示。

| 指标 | Base Checkpoint（微调前） | RLCD 微调后 | 变化幅度（Delta） |
| :--- | :--- | :--- | :--- |
| 决策准确率（Accuracy） | 0.3625 | 0.7510 | +0.3885 |
| 期望校准误差（ECE） | 0.1737 | 0.1321 | -0.0416 |
| Brier 分数（Brier Score） | 0.3155 | 0.0576 | -0.2579 |
| 平均置信度（Mean Confidence） | 0.5362 | 0.6195 | +0.0833 |

在微调前，base checkpoint 呈现出决策置信度偏高但预测准确度低下的失准状态，平均置信度达到 0.5362，而准确率仅为 0.3625。经过 RLCD 训练后，平均置信度温和上升至 0.6195，伴随准确率的大幅拉升，Brier 分数缩减了 81.7%，表明模型预测概率分布与真实二值结局的逼近程度显著提高。

针对测试集内的三类核心决策题型，评估分别统计了题目准确率：

| 题型标识 | 题目规模 | 微调前准确率 | 微调后准确率 | 准确率提升幅度 | 题型后校准温度 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| choice（单项与多项选择） | 600 题 | 0.2900 | 0.7383 | +0.4483 | 1.082（基于 123 校准样本） |
| score（分值与连续打分） | 800 题 | 0.3250 | 0.7075 | +0.3825 | 1.031（基于 152 校准样本） |
| noul（是非与二元判定） | 600 题 | 0.4850 | 0.8217 | +0.3367 | 1.096（基于 125 校准样本） |

三类题型中，choice 题型的相对提升幅度最显著，准确率从基线的 0.2900 跃升至 0.7383。noul 判定题型因形式更聚焦，微调后绝对准确率突破 0.82。在预留的 400 个校准样本上按题型独立拟合温度标量，各题型的温度系数均稳定收敛在 1.03 到 1.10 区间，反映出 RLCD 产出的未校准 logits 本身已接近中性概率尺度，未出现深度强化学习常见的极端过自信膨胀。

## 与官方基准及外部模型的对照

将本次在 GB10 上获得的评测结果与开源社区公布的对照基线横向对齐，能够清晰确认复现模型所处的性能水位。

| 模型与评测配置 | 准确率（Accuracy） | Brier 分数 | 期望校准误差（ECE） | 数据来源与口径说明 |
| :--- | :--- | :--- | :--- | :--- |
| 每类多数投票基线 | 0.461 | - | - | 统计启发式基线 |
| laya base checkpoint | 0.362 | - | - | 官方 README 公布的 zero-shot |
| 本次测试 base checkpoint | 0.3625 | 0.3155 | 0.1737 | 本次在 2000 题 held-out 上的实测值 |
| TypeSafe Jev 1.13.0 | 0.727 | 0.148 | 0.144 | Jev 官方 zero-shot 基线 |
| 标注者自一致性上限 | 0.735 | - | - | 数据集人类教师一致性统计 |
| **本次复现（GB10 单卡）** | **0.751** | **0.0576** | **0.1321** | **seed 0，有效 batch 64，352 updates** |
| laya 官方微调模型 | 0.766 | 0.062 | 0.213 / 0.081 | 官方 2xT4 DDP 运行，未提交结果文件 |

在相同底座下，微调前零样本水平本次实测为 0.3625，与官方公布的 0.362 高度吻合，验证了测试集划分与前处理流程的一致性。

本次复现得到的 0.751 准确率，超越了 Jev 官方商业模型的公开基线（0.727），同时也高出了人类标注者自一致性上限（0.735）。相较于 laya 官方给出的微调峰值 0.766，本次实验存在 1.5 个百分点的数值差距。在 Brier 概率评分维度，本次取得的 0.0576 优于官方记录的 0.062，验证了预测概率分布的紧凑性。

## 差异分析与实验局限

关于本次实测 0.751 与官方记录 0.766 之间存在的 1.5 个百分点差异，应当客观区分事实记录与归因推测。一个不可忽视的事实依据在于，laya 官方在项目文档中明确声明该行 0.766 结果尚未提交对应的原始结果文件（runs 产物），因此缺乏逐步训练曲线可供细粒度比对。

在技术实现层面，本实验与官方环境存在两项物理差异。其一是计算并行拓扑的改变，官方采用 2 张 T4 配合 DDP 运行，而本次实验采用单卡 GB10 配合累积步数实现等效 batch，两者在多样本高斯噪声采样序列的交错顺序上无法做到二进制层面的完全同构。其二是 GPU 架构与数值精度差异，Blackwell 架构（sm_121）下的 BF16 浮点张量计算与旧代 Turing 架构存在细微数值舍入区别，叠加策略梯度对采样扰动的敏感性，可能在 352 次更新中引入微弱的轨迹偏移。基于现有数据，这 1.5 个百分点的落差属于合理的数值波动区间，双方在能力档位上高度一致。

本实验存在以下明确的技术局限，读者在引用结论时需结合具体边界进行评估：

第一，单次实验缺乏统计方差。由于仅执行了 seed 0 的单次运行，未进行多随机种子的重复训练，当前数字无法推导出置信区间，亦未做统计显著性检验。

第二，校准误差口径不可直接对齐。本次评估中报告的 ECE（0.1321）基于在 400 个校准样本上分类别拟合标量温度后的概率输出计算；而官方指标列中分别列出了原始温度（0.213）与温度拟合后（0.081）两组数据，由于官方未开源其测试集 post-temperature 的具体分桶与映射脚本，两者的 ECE 绝对值不可直接做高低优劣的判定。

第三，评测覆盖度未包含全部辅助指标。官方报告中包含 soft accuracy（0.471）及 score MAE（0.242），本次运行的评测脚本未输出这两项指标，亦未给出不同业务工作流（workflows）维度的拆分对比。
