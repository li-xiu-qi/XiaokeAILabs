# 用 LoRA 微调图像生成模型：学习一个人物身份

[English](README.en.md) · [实验与复现](face_identity_lora/README.md)

当通用图像模型无法通过一段描述稳定生成某个具体人物时，可以尝试用少量授权照片训练 LoRA，让触发词在生成时关联这个身份。本实验使用 20 张训练图和 10 张留出参考图，展示数据准备、SDXL 微调和人脸特征评估的路径。

现有记录中，512 像素生成的 1000 步检查点在 7 张可检测人脸上，对目标参考的平均余弦相似度为 0.3232；2000 步为 0.2461。**未微调基线使用 768 像素，不能将这两个数相减解释为微调收益。** 样本仅包含一个身份，且未检测到人脸的结果未纳入相似度均值，结论不能外推到其他人物。详见[实验记录](face_identity_lora/README.md)。

训练和使用真实人物照片前，应确认数据许可与人物授权。[CelebA 协议](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html)限定非商业研究并禁止进一步发布或分发数据集；模型和评估权重适用各自条款。本记录保留历史汇总，无法从现有材料精确重建整个环境。

包含数据集照片的旧图已从当前版本移除，已有 Git 历史仍包含这些文件。
