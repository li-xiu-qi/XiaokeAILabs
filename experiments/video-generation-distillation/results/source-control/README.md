# 教师数据是否优于学生自产数据？一次小样本对照

[English](source-control.en.md) | 简体中文

当小模型用大模型生成的素材微调，变化是否来自教师素材本身？仅对比微调前后无法回答：同样的训练步骤和提示词，也可能让模型学到场景。我们为此补做同预算对照：同一个 Wan2.1 1.3B 学生，分别使用教师视频和学生自身生成的视频各训练 200 步，再与未微调基模比较。

**这次抽帧盲评没有显示教师数据组优于基模。** 单名 AI 对每段五帧打分，四段的提示词符合度和画面质量均分分别为基模 1.25 / 1.50、教师数据组 1.00 / 1.25、学生自产数据组 1.00 / 0.75，满分 2。样本只有两条提示词各配两个种子，不能推断总体质量，也无法判断运动质量；这些分数不是基准测试。

## 对照怎么做

六条训练提示词与种子相同。教师组使用 Wan2.2 TI2V 5B 经 ComfyUI 生成的六条视频，学生组使用 Wan2.1 T2V 1.3B 经 Diffusers 生成的视频。教师视频原预定八条，其中两条被事后排除，选择偏差会影响结果；学生组未进一步筛选。教师输出 512×512，学生输出 480×480，两套框架与模型不同，因此比较的是两条**数据生成路径的整体效果**，不能把差异归因于参数量或纯粹的教师能力。

两组学生训练都使用 LoRA rank 8、alpha 8、batch size 1、学习率 0.0001、200 步、49 帧、24 fps、480 像素和训练种子 7357。基模和两组 LoRA 采用同一学生模型、480×480、49 帧、30 步、CFG 5；四条留出记录由两条提示各配两个随机种子构成，训练数据不含这四条记录。相同种子只用于匹配学生推理条件，不代表不同模型间噪声轨迹相同。

## 结果与证据

| 组别 | 提示符合度 / 2 | 画面质量 / 2 | 运动连贯 |
| --- | ---: | ---: | --- |
| 基模 | 1.25 | 1.50 | 无法判断 |
| 教师数据组 | 1.00 | 1.25 | 无法判断 |
| 学生自产数据组 | 1.00 | 0.75 | 无法判断 |

三个结果各有四个评分，都是同一个评审者在不知 A/B/C 身份时查看每段第 0、12、24、36、48 帧所得。第一条提示对应的一个种子中三组都有圆环；另一个种子里效果很小。第二条提示的一个种子可见程度不一的水纹，另一个种子三组都难以辨认清楚的圆环。均分只描述这次主观评分；未完整播放视频，无法推断时间一致性。

## 可复现边界

训练提示和种子见 [训练清单](train-prompts.json)，教师素材 SHA-256 保留在[教师来源记录](teacher-subset.json)。原始教师训练视频、模型权重及两个 LoRA 不随此对照提交，训练工具源码的完整版本和权重快照也未完整锁定。因此可以复核公开抽帧拼图与评分，但无法在仓库内核验完整视频，亦不能仅凭仓库逐字节重跑训练。实验可按主 README 中的步骤重做，并在自己的环境记录软件版本及权重来源。

评估视频均由本次固定文本提示生成，无实拍人物；12 条 MP4 总计 771,059 字节，保存在实验设备上，未纳入仓库；仓库不含模型权重。来源模型卡 [Wan2.2 TI2V 5B](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B)、[Wan2.1 T2V 1.3B](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B-Diffusers) 及 [ComfyUI 适配发布](https://huggingface.co/Comfy-Org/Wan-2.2) 标记为 Apache-2.0；再分发模型时应遵守对应许可证。模型卡核对日期：2026-11-07。
