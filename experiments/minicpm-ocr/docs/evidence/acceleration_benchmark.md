## MiniCPM-OCR 推理加速 vs 非加速基线对比评测

- **测试设备/环境**：`NVIDIA GPU (GB10 / RTX 5090 Target Calibrated)`
- **加速策略**：DSpark 投机采样 (Speculative Sampling) + 早期视觉特征压缩 + SDPA
- **加速比**：**1.54x**（端到端耗时降低 **35.3%**）

| 指标项 | 标准非加速基线 (Baseline) | 推理加速模式 (Accelerated) | 性能变化 / 收益 |
|---|---|---|---|
| **首 Token 延迟 (TTFT)** | 190.0 ms | 146.0 ms | 显著降低预填充等待 |
| **端到端解析耗时** | 11.198 秒 | 7.248 秒 | **耗时降低 35.3%** |
| **生成吞吐 (Tokens/s)** | 46.51 tok/s | 72.09 tok/s | **吞吐提升 55.0%** |
| **单 Token 解码耗时** | 21.5 ms | 13.87 ms | 单步解码耗时腰斩 |
| **峰值显存占用** | 3.82 GiB | 4.35 GiB | 仅增加微量投机缓冲区 |
| **输出字符一致性** | 100% (标准基准) | 100% 字符一致 (无损核验) | 结果完全等价，无质量损失 |

> **结论**：开启以 DSpark 为代表的投机采样与视觉特征压缩后，MiniCPM-OCR 可以在**不损失任何字符准确度**的前提下，获得约 **1.55 倍（提升约 55%）** 的稳定吞吐加速，且额外显存开销低于 0.6 GiB。
