# 六库向量索引类型支持清单

## 这个文档是干嘛的

记录 Milvus、Qdrant、SurrealDB、LanceDB、ChromaDB、sqlite-vec 六个向量数据库各自支持的索引类型，区分向量索引与标量/全文索引，标注哪些在本次基准中实测过。供选型与后续扩展测试维度时参考。

## 总览

| 库 | 向量索引 | 标量/其他索引 | 本次基准实测 |
|---|---|---|---|
| Milvus | FLAT、IVF_FLAT、IVF_SQ8、IVF_PQ、IVF_RABITQ、HNSW、DISKANN、SCANN、GPU_CAGRA、ANNOY | INVERTED、BITMAP、SPARSE_INVERTED_INDEX | HNSW、IVF_PQ、IVF_SQ8、FLAT |
| Qdrant | HNSW（自研 Filterable HNSW）+ Binary/Scalar/Product 量化 | ACORN 过滤优化、Payload 索引 | HNSW、HNSW_PQ |
| SurrealDB | HNSW（自研）、DiskANN（微软 crate，64-bit） | FULLTEXT、COUNT、UNIQUE | HNSW |
| LanceDB | IVF_FLAT、IVF_SQ、IVF_PQ、IVF_RQ、IVF_HNSW_FLAT、IVF_HNSW_SQ、IVF_HNSW_PQ | RTREE、标量索引 | HnswPq、IVF_PQ |
| ChromaDB | HNSW（自研） | 无 | HNSW |
| sqlite-vec | v0.1.9 暴力扫描；v0.1.10-alpha 起自研 DiskANN + IVF | 无 | 暴力扫描 |

## Milvus

向量索引类型最全，覆盖内存与磁盘两大类。内存索引包括 FLAT、IVF_FLAT、IVF_SQ8、IVF_PQ、IVF_RABITQ、HNSW、SCANN、ANNOY、GPU_CAGRA；磁盘索引为 DISKANN。另支持稀疏向量的 SPARSE_INVERTED_INDEX。标量字段可用 INVERTED 和 BITMAP 索引。

索引构建在数据写入之后，每个 segment 独立建索引（详见 `FAISS索引规模限制与Milvus分段.md`）。

## Qdrant

向量索引只有 HNSW 一条路线，但通过量化扩展出多个变体：Binary Quantization、Scalar Quantization、Product Quantization。HNSW 为自研 Filterable HNSW，不是外部库封装。

另有 ACORN 搜索优化，针对多低选择性 payload 过滤场景提升召回，源码见 `qdrant/lib/segment/src/types.rs` 的 `AcornSearchParams`。

不支持 FLAT 作为独立索引类型，但 `SearchParams.exact` 设为 true 时走暴力精确搜索。

## SurrealDB

向量索引有两个独立实现：`DEFINE INDEX ... HNSW` 走自研 `idx/trees/hnsw/`；`Index::DiskAnn` 走微软 `diskann-vector` crate，仅 64-bit。本次基准测的是自研 HNSW。

非向量索引包括 FULLTEXT（全文搜索，支持 BM25 排序与分词器）、COUNT（计数）、UNIQUE（唯一约束）。

## LanceDB

全部为 IVF 系列，共 8 种向量索引，源码枚举位于 `lance/rust/lance-index/src/lib.rs`：

- IVF_FLAT、IVF_SQ、IVF_PQ、IVF_RQ
- IVF_HNSW_FLAT、IVF_HNSW_SQ、IVF_HNSW_PQ

没有独立的 FLAT 或 HNSW 索引，不建索引时走全量暴力扫描。标量字段支持 RTREE 等索引类型。

本次基准测的 HnswPq 属于 IVF_HNSW_PQ，是 HNSW 加乘积量化的组合，默认参数下召回偏低（0.537），需要调参才可比。

## ChromaDB

向量索引只有 HNSW 一种，自研实现。不支持 FLAT 暴力搜索作为独立索引类型，也不支持 IVF 系列。HNSW 参数通过 collection metadata 配置（`hnsw:M`、`hnsw:construction_ef`、`hnsw:search_ef`），但查询时不接受运行时 ef 参数，只能测固定 ef 值。

无标量/全文索引能力。

## sqlite-vec

版本分水岭明显。基准所用的 v0.1.9 只有暴力扫描，无任何 ANN 索引。当前 main（0.1.10-alpha）已加入自研 C 实现的 DiskANN 和 IVF（`sqlite-vec-diskann.c`、`sqlite-vec-ivf.c`），但尚未正式发布。

## 对基准测试的意义

本次测试只覆盖了每个库的一到两种索引。如果要扩展测试维度，Milvus 和 LanceDB 的索引矩阵还有大量未测组合（IVF_SQ8、SCANN、DISKANN、IVF_RQ 等），Qdrant 的量化变体也未展开。
