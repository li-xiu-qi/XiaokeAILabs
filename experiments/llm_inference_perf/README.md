# llm_inference_perf：本地大模型推理性能实验

## 这个实验测什么

本地大语言模型在统一内存设备上的**推理性能机制**，当前阶段聚焦**投机解码**（speculative decoding）：给主模型挂一个草稿模型提前猜若干 token、主模型批量验证，用额外计算换吞吐。测的是这套机制在什么条件下有正收益、关键参数怎么影响收益。

以机制为轴，不以工具为轴：自变量是任务类型、草稿类型与投机参数（草稿长度、置信度阈值、并发数），不是"哪家产品快多少"。阶段二起把**任务类型**也设为自变量（三类任务：自由生成、长文本改写、代码改写）。

## 不测什么

- **模型质量与准确率**：跳过。本实验只测速度类指标（生成吞吐、预填充吞吐、草稿接受率）。草稿接受率是机制指标，不是模型能力指标。
- **训练与微调**：不涉及。
- **多轮对话、并发压力**：当前单请求串行，并发场景未测（结论的适用范围限制之一）。
- **长上下文下的衰减**：上下文固定档位测试，未做上下文长度扫描。

## 数据来源

全部为**真实模型在真实硬件上的实测**，非合成、非仿真。原始输出为 llama.cpp 服务端 `print_timing` 日志与 HTTP 响应内的 `timings` 字段，两者交叉核对。

## 复现命令

依赖：仅需 `python`（标准库，无第三方包）与一个已编译 CUDA 支持的 llama.cpp。

```bash
# 1. 起基线服务（无投机解码）
bash scripts/start-server.sh base

# 2. 起投机服务（MTP 或 DFlash2）
bash scripts/start-server.sh mtp        # MTP 版
bash scripts/start-server.sh dflash     # DFlash2 版

# 3. 发统一测试请求并提取指标
python scripts/bench.py --host 127.0.0.1 --port 8835 --n-predict 400
```

脚本内路径用环境变量覆盖（`LLAMA_BIN`、`MODEL_DIR`、`DRAFT_MODEL`），默认值面向 GB10 设备的常见布局，换机器时改环境变量即可。

## 结论速览

当前有效结论见 `reports/03-三模型投机矩阵-任务类型与参数交互.md`，四条：

1. **任务类型是收益的第一变量，模型结构是第二变量**。同一模型下改写类任务收益高于自由生成（125B：+16.4% 对 +57.0%；27B：+54.3% 对 +131.4%）；同一任务下稠密模型收益高于 MoE（T2 改写：27B 2.33× 对 125B 1.32×）。
2. **`p_min` 留 0.0，让草稿跑到 `n_max` 上限**。接受率高不等于收益高，真正的决定量是每轮主模型前向产出的 token 数。
3. **`n_max` 有上限（125B 上是 3）**，超过转为负收益。
4. **N-gram 系列的三种变体在改写与生成类任务上全部失效**，只在「大段原样复制」场景适用。

阶段一的三条旧结论（MoE 挂草稿净亏、125B MTP 零收益、对 MTP 过滤低置信度是净赚）已被阶段二数据推翻，保留在阶段一报告中供追溯。
