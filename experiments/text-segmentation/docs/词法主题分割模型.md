# 词法主题分割：TextTiling / C99 / BM25 边界

> 实证日期 2026-09-08 · BAAI/bge-small-zh-v1.5 · 脚本 `scripts/algo_texttiling.py`、`algo_c99.py`、`algo_bm25_boundary.py`

这三个算法共享一个前提：**主题转移表现为词汇分布的突变**。它们不看语义，只数字面词项的重合情况，因此零模型依赖，在不能跑神经网络的场景仍然可用。

## 三个算法的判据不同

**TextTiling（Hearst, 1997）**：把文本切成固定长度的伪句，算相邻伪句的词袋余弦相似度，得到一条相似度曲线，在曲线的「谷底」断句。谷的深度 = 该局部极小值到左右峰顶的落差均值。它要求平滑窗口来压制局部噪声，但平滑同时会抹平真实的短主题段。

**C99（Choi, 2000）**：不做曲线，做矩阵。句子两两余弦得 n×n 相似度矩阵，按列做 rank transform 后，同一主题的句子在矩阵里聚成方块。用贪心 divisive 聚类递归切分，每次切在「使切分后内部密度提升最大」的位置。密度 = 块内相似度均值。它对短文档友好，但 O(n²) 的矩阵在长文上需要截断（本实现限制 200 句）。

**BM25 边界打分**：把相邻句对当作查询-文档，用带饱和与长度归一化的 BM25 权重衡量两句的独立性。1 - 余弦即边界分，超过百分位阈值即断。与 TextTiling 的差别不只是权重公式：TextTiling 用原始词频，BM25 用 IDF 加权且对文档长度归一化，对「高频虚词偶然共现」更不敏感。

## 中文上的差距从这里来

中文没有空格分词，虚词（的、了、是、在）占比显著高于英文。原始词频余弦会被这些高频共现词拉高，使得相邻两句即使主题不同也显得相似。BM25 的 IDF 加权直接压掉这个效应，这解释了实测中 BM25 边界明显优于 TextTiling。

## 选型边界

三个算法都假设「词汇换了 = 主题换了」。这个假设在两类内容上失效：同一主题换用同义词表述（词汇全变、主题不变），和不同主题共用同一批术语（词汇不变、主题变了，典型如技术文档的参数表）。这两种情况下词法方法必然给出错误的边界。

如果需要覆盖这两种情形，必须上语义算法或 LLM。

## 实测数据

见 `results/` 与 README 汇总表。BM25 边界的 F1@32 超过多数语义算法配置，是这个前提假设成立时词法方法的可用性证据。
