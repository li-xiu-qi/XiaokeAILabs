# 五组训练信号的运行记录

[English](README.en.md)

本次固定 SciFact 的 390 条训练、89 条开发及 300 条测试查询；各查询最多使用 BM25 的 30 个候选，训练候选由一个标注相关项和一个未标注项组成。未标注不代表不相关。数据准备及模型版本见[实验入口](../../README.md)。测试集在先前实验中使用过，不是独立盲测。

`plan.json` 保存固定候选池哈希、训练条件、随机种子以及教师对候选的偏好统计。五种信号分别为 `human`、`teacher_hard`、`teacher_soft`、`human_hard` 和 `human_soft`；各组使用相同采样计划和 180 步优化，三个种子只改变训练随机性。硬排序遇平分选择训练对第一项，即已标注相关项；软分数使用教师 yes/no logit 之差，经温度 2 的两项 softmax 转换，并非经校准的相关概率。

`*-training.json` 保存每一步损失，`*-eval.json` 保存开发集和测试集逐查询指标，`*-scores.json` 保存每个候选的学生分数；文件名包含组别和种子。`summary.json` 包含逐种子均值、样本标准差及探索性比较；从实验目录运行 `python scripts/summarize-five-arms.py` 可从逐查询证据复算。查询 bootstrap 在三个种子取均值后进行，不包含种子间训练波动，且未对多重比较校正。教师和学生模型的输入长度、精度不同；混合损失的系数相同不代表各项梯度贡献相同。

模型权重、原始文献和教师分数不包含在此目录。教师使用 Qwen3-Reranker-8B，学生使用 ms-marco-TinyBERT-L2-v2；教师开发集优势与版本见[原实验记录](../qwen3-8b/)。

公开的五组脚本在同一台 DGX Spark 上使用同一教师分数、候选池与学生检查点完整复跑；15 次运行的测试 nDCG@10 均与原运行一致，精确到小数点后九位。复跑前的教师门槛和运行配置分别保存在 `public-replay-teacher-gate.json` 和 `public-replay-plan.json`；这不等于在其他设备或不同软件环境下保证数值完全相同。
