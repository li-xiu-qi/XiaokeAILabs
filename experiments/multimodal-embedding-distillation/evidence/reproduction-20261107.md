2026-11-07 在 DGX Spark GB10 上，使用公开脚本重新完成数据准备、教师编码和两组学生训练。固定的 100 条测试查询中，基线、监督和蒸馏三组排名分别与[先前公开记录](student-test-ranks.json)逐项一致；教师的 R@1、R@5、MRR 分别为 0.94、1.00、0.965833，与原汇总一致。这是相同设备、缓存模型版本和数据条件下的一次复核，不保证跨设备或跨版本一致。

## 条件与操作

脚本对应提交 `f1aa627`，运行 Linux、Python 3.12、PyTorch 2.14.0+cu130、Transformers 5.16.1、Sentence Transformers 6.0.1。教师 revision 为 `5c54692f22e186fc12ea38a9193e3ff9e1cda2a3`，学生 revision 为 `cc4c733ed997dbee4ac70ccffb911e70c9c24b93`。使用的标注 SHA-256 为 `395990db603ab8bafd5c7ab2746b22058bb1e75b78b3eb56ad755931364ac137`；新生成的样本清单 SHA-256 为 `c9aaf627f76439c479fcdc2b03595be3bdc62c829a7baa5651e982af4e83dfec`，与原清单相同。

在全新工作目录依次执行主 README 的 `prepare.py`、`teacher.py`、`train.py` 和 `verify.py` 命令：数据准备抽取 512 / 128 / 100 张图，740 张均可解码且选中图片没有字节级重复；调度时观察到教师编码与学生训练均退出码 0，日志未单独保存退出码。`verify.py` 复算的是既有公开排名；另外将本次生成的三组 100 条测试排名与该记录逐项比较，三组均 100/100 一致。结果 JSON 含计时等运行信息，新旧文件 SHA-256 不同，不能称为字节一致。

每阶段由独立进程监控系统可用内存，低于 50 GiB 时中止本次进程组。教师阶段最低记录 87.62 GiB，学生阶段 88.78 GiB；教师含加载约 88.03 秒。两阶段启动至退出的守护日志区间约 93 秒和 44 秒，不能直接解释为纯模型计算时间。此记录不包含对其他硬件、并发或不同数据的验证。
