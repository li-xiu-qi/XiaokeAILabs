# 显存、批次与语料内存基准 (NVIDIA GB10)

> 职责声明：本报告来自 climbmix / smoltalk 真实语料在单张 GB10 级 GPU 上的历史运行，测了分词器域偏差、词表规模与显存批次基准，没测多机分布式与最终模型能力；后续做词表选型、显存预算与数据量级规划时可引用，引用时注明为单卡历史实测。
