# 多模态 Embedding

图文嵌入模型的两个阶段：推理时怎么用，想自己训怎么训。

| 实验 | 阶段 | 内容 |
|---|---|---|
| `test_bge_vl/` | 推理验证 | BGE-VL 视觉-语言嵌入的上手实测：图文混合输入编码、文搜图相似度验证，单模型快速验证性质 |
| `test_finetune_clip/` | 训练 | CLIP 轻量微调：冻结视觉 / 文本塔大部分层只训少量参数，降低显存与训练成本（Flickr30k） |

要的是系统级图文模型部署流水线（原生推理与封装、ONNX/OpenVINO、NNCF INT8 量化），看平级的 `jina_deployment`，那里管生产部署，本组管模型本身。
