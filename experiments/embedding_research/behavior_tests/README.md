# 嵌入模型行为专项

一组实验测的是同一件事的不同侧面：**普通文本嵌入模型的余弦相似度，在什么条件下会骗人**。都是单变量专项，结论回答「模型的区分力够不够用」，不构成模型横评。

| 实验 | 动的变量 | 回答的问题 |
|---|---|---|
| `test_sentence_length/` | 句子长度 | 长短句的相似度基准不同，固定阈值判断「像不像」会误判 |
| `test_sentence_similarity_with_code_or_table/` | 内容类型（代码块、Markdown 表格） | 普通文本模型对结构化内容的分辨力有限，RAG 混排文档会错配 |
| `test_nli_merge_sim_transfer/` | 数据格式（NLI 蕴含 / 中性 / 矛盾句对） | 把 NLI 句对当训练信号迁移时，模型自身的区分力够不够 |
| `test_crossmodal_retrieval/` | 模态（图对文、音对文）、模型、词序 | 换成跨模态之后，余弦相似度还能不能信 |

两个层次，先文本内后跨模态。前三个实验在同一个编码器内部动输入，第四个换靶子：编码器变成两个（图文双塔）或一个统一塔，机制完全变了一轮。

## 各实验状态

`test_sentence_length` 已做完五批：主实验 2100 个相似度、用词因素 3000 个、词级与表达谱与段落级 9400 个、段落推到 16 段、功能词等长替换。2026-09-26 随四因素落地改名，原名「句子长度对相似度计算的影响」。

`test_crossmodal_retrieval` 已做完六组：检索基线、硬负样本、双路由对照、词序扰动、音频基线、同模型内图文音对照。三个模型。详见其目录 README。

`test_sentence_similarity_with_code_or_table` 与 `test_nli_merge_sim_transfer` 状态见各自目录。

## 共用框架

获取嵌入（本地 SentenceTransformers 或封闭 API）→ 算余弦相似度 → 画分布图对照基准。改模型路径与数据定义即可复用。其中 `test_nli_merge_sim_transfer` 是工具库性质，入口脚本与数据不在仓内。

## 两条跨实验的结论

前三个实验合起来给出：方向由机制决定，幅度由模型决定，极差 4.7 到 5.4 倍。

跨模态实验给出另一半：折扣幅度受模型与模态两个变量控制。模型决定同一模态内的幅度（差一倍），模态决定量级（同一模型内音频与图文差 40 倍）。

合起来是：相似度分数的方向由机制决定，幅度由模型决定，量级由模态决定。任何不说明是哪个模型、哪个模态的相似度阈值都没有意义。
