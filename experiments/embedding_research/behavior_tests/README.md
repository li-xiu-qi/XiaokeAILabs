# 嵌入模型行为专项

三个实验测的是同一件事的不同侧面：**普通文本嵌入模型的余弦相似度，在什么条件下会骗人**。都是单变量专项，结论回答「模型的区分力够不够用」，不构成模型横评。

| 实验 | 动的变量 | 回答的问题 |
|---|---|---|
| `test_sentence_length/` | 句子长度 | 长短句的相似度基准不同，固定阈值判断「像不像」会误判 |
| `test_sentence_similarity_with_code_or_table/` | 内容类型（代码块、Markdown 表格） | 普通文本模型对结构化内容的分辨力有限，RAG 混排文档会错配 |
| `test_nli_merge_sim_transfer/` | 数据格式（NLI 蕴含 / 中性 / 矛盾句对） | 把 NLI 句对当训练信号迁移时，模型自身的区分力够不够 |

三个实验共用同一套框架：获取嵌入（本地 SentenceTransformers 或封闭 API）→ 算余弦相似度 → 画分布图对照基准。改模型路径与数据定义即可复用。其中 `test_nli_merge_sim_transfer` 是工具库性质，入口脚本与数据不在仓内。

部分结论已并入 `test_text_segmentation` 的选型边界（分块策略与检索质量的关系），那里保留结论，本组保留原始实验过程与可视化。
