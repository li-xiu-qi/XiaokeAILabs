# NLI 数据上的嵌入相似度迁移

三个脚本支撑同一个实验思路：普通嵌入模型（BGE-M3 一类）在 NLI（自然语言推理）数据格式上的相似度表现，用来判断把蕴含/中性/矛盾句子对当训练信号做迁移时，模型自身的区分力够不够。

| 文件 | 作用 |
|---|---|
| `embedding_models.py` | 嵌入封装：硅基流动 API 与本地 SentenceTransformers 两条路径 |
| `cached_embedding_models.py` | 带缓存的版本，重复实验不重算 |
| `plot_func.py` | 余弦相似度结果可视化，按与基准的差异着色 |

三文件是工具库性质，实验的入口脚本和数据不在此目录，跑之前先确认来源。
