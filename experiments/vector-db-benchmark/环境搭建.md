# 环境与测试方法

目前可运行的示例为 `scripts/safe_sqlite_bench.py`：安装 Python 3、NumPy、sqlite-vec 后，它使用全新内存数据库和确定性合成数据，进程退出后数据库自然消失，不访问本地数据库或服务。运行命令及指标说明见[实验入口](README.md#安全运行sqlite-vec-合成数据基准)。

历史多库基准和探测脚本可能使用固定资源名或删除路径，部分入口已禁用，不能按历史命令直接运行。其他历史脚本未全部加禁用保护，例如 `gen_emb.py` 会写入固定路径并可能覆盖原有文件；请勿直接运行。后续需为每次运行创建独立资源并验证清理范围，再逐项恢复适配器。历史数据缺少原始结果，不作为产品排名。
