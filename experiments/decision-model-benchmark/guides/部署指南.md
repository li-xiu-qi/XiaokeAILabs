# Jev 系列实验：部署指南

这份指南面向只想在本地部署一个 Jev 类模型、接入自己业务的人。不需要跑完全部四个模型，也不需要对齐报告里的数字。

想复现整套评测，看《复现教程.md》。各模型的延迟、准确率、显存实测见[基准报告](../../../docs/zh/decision-models/判别式决策模型基准实测.md)。

## 先选模型

| 模型 | 参数 | 延迟（中位数） | 中文 | 常驻显存 |
|---|---|---|---|---|
| Laya | 1.1B | 16.98 ms（英文）/ 8.25 ms（中文） | 分类可用，命题判断失效 | 5.96 GB |
| metask-jev | 4B | 133.5 ms（英文）/ 133.7 ms（中文） | 分类 20/20 | 8.58 GB |
| Nimble | 9B | 365.33 ms（英文） | 上游声明仅英文，未测 | 17.57 GB |

只用英文、要最低延迟和最小显存，选 Laya。要中文分类，选 metask。字段数固定且业务只跑英文，才考虑 Nimble。

## 机器要求

历史评测使用 Linux 和 NVIDIA CUDA 设备。结果表中的显存是该次运行的观测值，不是设备最低要求；不同模型、批次和输入会改变峰值。权重和缓存需要额外磁盘空间，Nimble 合并权重时还需要同时容纳基座和合并产物。各架构的依赖和实际可用容量以子目录说明及自身环境检查为准。

## 装环境

```bash
python -m venv /path/to/your-venv
source /path/to/your-venv/bin/activate

# 国内网络拉 Hugging Face 需要设置镜像端点
export HF_ENDPOINT=https://hf-mirror.com

# 按 https://pytorch.org/get-started/locally/ 选择并安装适用于设备的 CUDA 版 PyTorch
pip install transformers==5.16.1 accelerate peft==0.20.0 numpy
python -c "import torch; print('torch:', torch.__version__, 'CUDA:', torch.cuda.is_available()); assert torch.cuda.is_available()"
```

这些命令只是准备依赖的示例，并非完整锁定环境。不同路线的要求不一定兼容，优先按各子目录 README 建立独立环境；升级后应重新验证模型调用。

## 生产环境注意事项

不要同时驻留多个模型，跑完一个释放显存，再加载下一个。应按实际输入和并发测量峰值，不能仅按常驻值预算。

输入长度直接影响单次前向耗时。本系列实测用的是 86 字符的短输入，真实业务输入更长，上线前用自己的真实数据测一遍延迟。

metask 的 `metask-temperature.json` 是上游拟合的置信度校准系数，输入分布和训练数据差得远时，建议用自己的数据重新校准，不要直接采信原始概率。
