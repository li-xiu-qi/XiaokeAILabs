# 判别式决策模型部署与基准评测（decision-model-benchmark）
[English](README.en.md)

本实验评估四种主流开源类型化判别式决策模型与标准生成式大模型在工单分类与逻辑命题判定上的**推理延迟、显存占用与置信度校准**。对应原理与结论分析见[判别式决策模型评测与微调](../../docs/zh/decision-models/决策模型架构评测与选型.md)。

## 评测方案全景

| 子目录 | 被测对象与底座 | 核心架构机制 | 评测重点 |
|---|---|---|---|
| [laya-dual-branch/](laya-dual-branch/) | Laya (0.3.5) | 专用双分支判别模型，内置英文与多语言路由分发 | 作为基准协议，评估双分支延迟与准确率 |
| [metask-logits/](metask-logits/) | metask-jev-4b (Qwen3.5-4B) | 约束候选答案为单个 Token，直接读取输出层 Logits 归一化 | 4B 参数下单 Token Logits 概率校准与满分准确率 |
| [nimble-lora/](nimble-lora/) | Bespoke-Nimble-9B | 基座模型 + LoRA 适配器，需离线完成权重合成 | 9B 较大模型在本地单卡上的延迟与显存开销 |
| [omni-multimodal/](omni-multimodal/) | Jev-Omni (Gemma 4 12B IT) | 支持文本、图像、音频、视频四类输入的多模态决策模型 | 多模态输入下的推理延迟与概率分布可用性 |
| [baseline-llm/](baseline-llm/) | Qwen3-VL-4B 对照组 | 标准自回归生成式模型 | 生成式大模型与判别式模型在单次决策上的耗时量级差异 |

## 环境准备

各路线依赖和模型不同，分别按子目录 README 创建独立环境，并准备 CUDA 设备、网络和模型存储空间。Jev-Omni 还需要音视频处理工具及测试素材。各脚本内含基准输入，无需另行准备分类数据集；多模态素材的获取方式见对应子目录。历史评测配置和下载步骤不构成完整依赖锁，其他系统与显存容量需自行验证。
