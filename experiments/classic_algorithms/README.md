# 经典算法：不依赖框架的从零实现与实测

经典计算机科学算法的动手实验，标准是脱离库函数自己写核心逻辑，跑出可验证的结果。与 AI 相关的算法实验（相似度、聚类）各有归属，本系列收的是教科书意义上的经典算法：图论与选择算法。

## 子目录

| 目录 | 问题 | 内容 |
|---|---|---|
| `bfprt_dual_impl/` | 第 k 小/中位数怎么在最坏 O(n) 内求出 | BFPRT 与快速选择的 Python/Rust 双实现，实测对比两者在不同数据分布下的真实表现 |
| `graph/` | 图上的遍历、路径与连通怎么算 | DFS/BFS、Dijkstra 最短路径、Kruskal 最小生成树（含并查集），networkx 对照加 matplotlib 可视化 |

## 两个实验共同的读法

都是「先写教科书实现，再和库或另一种写法对比」。bfprt_dual_impl 里值得看的是那组实测结论：BFPRT 理论最坏 O(n)，但分组、选主元的常数开销让它在随机数据上反而慢于快速选择，只有数据可能被恶意构造时才值得。graph 里值得看的是手写版与 networkx 的结果互验，以及可视化部分怎么把算法过程画出来。

## 目前没有的

排序算法（快排、归并）还没有实验。哪天补了，和选择算法放一起正好对照：同一批输入，排序 O(n log n) 全序输出，选择 O(n) 只取目标名次，相同 partition 机制的不同用法。
