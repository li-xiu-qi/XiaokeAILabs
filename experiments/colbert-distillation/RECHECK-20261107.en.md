# Rerunning real teacher scoring and student training

[简体中文](RECHECK-20261107.md) | English

On 2026-11-07 we reran Qwen3-Embedding-8B teacher scoring and the ColBERT student experiment with the public scripts that bind scores to input hashes. Query IDs and candidate order matched the historical training and test manifest; input bindings and finite teacher scores passed. Complete candidate order for all 300 queries matched the historical baseline and supervised runs. **The new distilled result differed from the historical run**: completing the pipeline does not establish byte-for-byte reproduction.

| Condition | nDCG@10 | MRR@10 |
| --- | ---: | ---: |
| Base | 0.653562 | 0.626175 |
| Label supervision | 0.668572 | 0.645220 |
| Teacher-score distillation | 0.669450 | 0.646532 |

Across the same 300 paired queries, distilled minus base nDCG@10 was +0.015888 with a 10,000-sample paired-bootstrap 95% percentile interval of [0.003933, 0.028870]. Distilled minus supervised was +0.000878, interval [-0.005669, 0.007639]. This run did not meet the preset target of a gain of at least 0.02 over base; the comparison with supervision does not establish an advantage. Each run uses one training seed, so the intervals do not capture training variability. Training and test queries share the document corpus; unjudged candidates are not guaranteed negatives.

## Differences from the historical run

The new distilled group changed the full candidate order for 243 of 300 queries and nDCG@10 for 12; the historical distilled result was 0.665310 / 0.642079. Across the same 9,512 candidate scores, the mean absolute difference between new and historical teacher scores was about 0.001266 and the maximum 0.007520. The implementations and numerical processing may differ, but the available evidence does not identify a specific cause of the ranking changes.

[Anonymous paired per-query metrics](recheck-per-query.csv) contain no query or document text. Run `python recompute_recheck.py` to reproduce the means, differences and intervals. The metrics alone do not validate ranking, candidates or labels. Row indices are for pairing the three groups in this rerun and should not be used to join historical records by position.

## Conditions

Public scripts correspond to commit `4d6d85a`, on DGX Spark with Python 3.12, PyTorch 2.14.0+cu130, Transformers 4.56.2, Sentence Transformers 5.1.1 and PyLate 1.4.0. Candidate-pool SHA-256: `e7cac48e7083bdd948e2773136c1df9672b4ca8f787ee5b774697b32d689c5f8`; corpus and query hashes are in [source-hashes.json](source-hashes.json). Model provenance, inputs and applicable licenses are in the [main README](README.en.md).

We ran the README's `prepare_teacher.py --device cuda` and `run.py` commands in a new directory for real teacher scoring and the base, supervised and distilled student conditions; both guarded stages returned exit code 0 in the orchestration session. An independent monitor stopped the experiment process group below 50 GiB available memory; observed minima were 75.91 and 89.97 GiB. Guarded intervals were approximately 5 min 54 s and 2 min 59 s, including loading and evaluation, not pure throughput measurements. Model weights, original document text and full per-candidate outputs are not redistributed here.
