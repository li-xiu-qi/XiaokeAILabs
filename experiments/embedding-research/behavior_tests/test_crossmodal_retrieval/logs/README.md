## 读日志时要注意的三件事

**时间戳的不一致是真实的，不是记录错误。** A 到 D 组的日志用 `[HH:MM:SS]` 前缀，是脚本自己打的；E 与 F 组用相对耗时（`已用 82s`），是另一套脚本。所以 D 组日志开头是 `00:23` 而 A 组是 `23:58`，同一次连续运行跨过了午夜。

**`图像可用 500/500` 这一行是有效样本数，写读数时必须核对它。** 本次它等于预期样本数，所以读数有效。如果它小于预期，说明有图像编码失败，此时所有后续统计口径都要重新说明，详见踩坑一节。

**E 组日志里 `不报折扣比例` 那条 note 已被 F 组取代。** E 组当时缺同源分母所以留空，F 组换模型后补上了分母，音频折扣 1.7%。两处措辞不同是同一个问题在两个时间点的状态，不是矛盾。
