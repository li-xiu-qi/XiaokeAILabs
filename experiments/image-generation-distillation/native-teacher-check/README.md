# 1024px 教师的场景优势检查

前一轮相机产品图的教师优势检查未过门槛，其中 SDXL 教师以 512px 输出。由于 [Diffusers 文档建议多数 SDXL 模型使用 1024px](https://huggingface.co/docs/diffusers/api/pipelines/stable_diffusion/stable_diffusion_xl)，我们使用新的开发组合，在模型各自的输出设置下再做一次筛查：SDXL 教师生成 1024px 图片，再用 Pillow LANCZOS 缩至 512px；SD 1.5 基线直接生成 512px 图片。两组使用相同提示、整数种子、30 步和 guidance 7.5，各用各自的调度器；教师采用 model CPU offload。

一名 AI 评审逐张查看匿名的 64 张 512px 图片。32 个配对中，7 对含 unknown，余下 25 个有效配对的复合成功数为教师 5、学生 0。复合成功要求同时有一台可辨相机、颜色和背景正确且没有严重伪影。

| 单项指标 | 学生 | 教师 |
| --- | ---: | ---: |
| 单台可辨相机 | 12/32，另 4 张 unknown | 20/32，另 4 张 unknown |
| 相机颜色符合 | 7/32 | 19/32 |
| 背景符合 | 13/32 | 25/32 |
| 严重伪影 | 24/32 | 20/32 |

按既定规则，门槛为至少 28 个有效配对、教师至少 20 个复合成功，且比基线多至少 4 个；本次只满足第三项，**因此不启动后续训练**。在这组数据上教师有更高的单项计数，但一名 AI 评审、少量相似场景和 unknown 限制了推断。该轮与前一轮使用不同开发组合，不能把两轮结果的变化归因于分辨率；模型、生成分辨率、调度器及重采样共同构成被比较方案，也不能把差异归因于某个单独因素。

新开发集和新留出集各包含 32 个完整属性组合，与前轮训练、开发、测试组合均不重叠。留出集尚未使用；组合不重叠不代表语义完全独立。1024px 原图与评分缩图分别保留，64 张评分图的揭盲映射、提示和哈希经过校验。本目录提供开发清单、逐图评分及复算数据，不包括全部原图和留出清单；复算统计不能替代审阅图片。门槛与划分的先后顺序有本地文件和会话记录，但没有第三方可信时间戳，不能由本公开包独立证明。

```bash
python check_development_gate.py --scores revealed.csv
```

门槛和数据划分先于评分的顺序来自本地记录，没有独立可信时间戳；未公开留出清单，读者无法独立核验跨轮划分或图片哈希。
