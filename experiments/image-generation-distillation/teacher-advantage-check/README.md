# 先检查教师：一次未通过的图像生成对照

在用大模型生成数据训练小模型之前，先问一个更基本的问题：教师在目标场景中是否展示了学生可以学习的优势？这次以相机产品图为场景，对 SDXL 教师和 SD 1.5 原始学生进行了预先设定门槛的开发集盲评。

32 条属性组合各由两个模型生成一张图，一名 AI 评审逐张查看匿名的 512 × 512 原图。成功定义为同时满足“一台可辨认相机、相机颜色正确、背景正确、没有严重伪影”；任一项目为 unknown，则整对不计入有效配对。

| 开发集结果 | SD 1.5 学生 | SDXL 教师 |
| --- | ---: | ---: |
| 单台可辨相机 | 12/32，另有 6 张 unknown | 6/32，另有 3 张 unknown |
| 背景正确 | 11/32 | 18/32 |
| 严重伪影 | 21/32 | 21/32 |
| 复合成功，有效配对内 | 1/24 | 0/24 |

共有 8/32 对因为至少一张图存在 unknown 而不进入复合成功统计。预设门槛要求至少 28 个有效配对，并且教师至少成功 20 个、较学生多成功至少 4 个。**门槛未通过，因此我们停止了这轮微调和最终测试。**这一结果不足以对模型做通用排序：评审是单次 AI 主观判断，样本量有限；教师与学生使用各自的 PNDM 和 Euler 调度器，且这里的 SDXL 输出为 512px，[Diffusers 文档指出多数 SDXL 模型在 1024px 下表现最佳](https://huggingface.co/docs/diffusers/api/pipelines/stable_diffusion/stable_diffusion_xl)。本次发现也不能推广到教师的其他分辨率或场景。

提示涉及相机颜色、背景、视角和光照的固定组合；两模型使用相同提示和整数种子、30 步、guidance 7.5。相同整数种子不保证跨模型生成相同噪声。严重伪影按明显几何畸变、拼贴或物体混成判定，摄影灯入镜本身不算严重伪影；相机缺失时颜色计为不符合。模型输出和独立评审均有随机性与主观性。

## 复算

`revealed.csv` 保存全部逐图评分，`development.jsonl` 是开发集输入。执行以下命令校验 32 对是否完整，并按预设门槛复算：

```bash
python check_development_gate.py --development development.jsonl --scores revealed.csv
```

设备上生成的 68 个输出文件与本地备份逐一通过 SHA-256 核验；本目录没有收录全部生成原图。复算只能验证评分统计，不能替代重新查看图片。

门槛与提示在评审前记录；现存文件时间可被修改，没有独立可信时间戳，仅凭公开文件不能证明先后顺序。
